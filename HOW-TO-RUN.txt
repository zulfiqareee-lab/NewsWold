=====================================================
  NEWS WORLD - প্রজেক্ট রান করার নিয়ম (বাংলা নির্দেশিকা)
=====================================================

আপনি GitHub Actions থেকে সফলভাবে প্রস্তুত প্যাকেজ ডাউনলোড করেছেন!

১. প্রয়োজনীয় সফটওয়্যার:
   - আপনার কম্পিউটারে Node.js (v18 বা v20+) ইনস্টল থাকতে হবে।
   - ইনস্টল না থাকলে https://nodejs.org/ থেকে ডাউনলোড করে নিন।

২. ১-ক্লিকে চালানোর নিয়ম:
   - উইন্ডোজ (Windows) ব্যবহারকারী হলে:
     "start-windows.bat" ফাইলের উপর ডাবল ক্লিক করুন।
     এটি স্বয়ংক্রিয়ভাবে ডিপেন্ডেন্সি সেটআপ করে ব্রাউজারে http://localhost:3000 খুলে দেবে!

   - ম্যাক বা লিনাক্স (Mac / Linux) ব্যবহারকারী হলে:
     টার্মিনাল খুলে লিখুন:
     chmod +x start-mac-linux.sh
     ./start-mac-linux.sh

৩. ম্যানুয়ালি টার্মিনালে চালানোর নিয়ম:
   - কমান্ড প্রম্পট বা টার্মিনালে এই ফোল্ডারে আসুন:
     npm install
     npm run dev
   - ব্রাউজারে যান: http://localhost:3000

৪. লাইভ সার্ভারে বা হোস্টিংয়ে আপলোড করতে:
   - আপনি যদি cPanel, Vercel, Netlify ইত্যাদিতে আপলোড করতে চান,
     তবে GitHub Actions থেকে "NEWS-WORLD-Static-Website-dist" ফাইলটি নামিয়ে
     সরাসরি আপনার হোস্টিংয়ের public_html বা ডিরেক্টরিতে আপলোড করতে পারবেন।
